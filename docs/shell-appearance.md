# Shell 主题启动与状态栏资源（2026-11-09）

## 首次登录主题

Shell 使用独立的 SDK Embedded Application，之前仅在构造时读取图标主题与字体，之后由装饰主题的深浅色/强调色变化触发重绘。ShellThemeFollower 现在跟随真实 Appearance 客户端的服务出现与属性变化，在服务晚启动或重新出现时应用图标主题；装饰颜色变化不再覆盖已经获取的图标主题。

## 状态栏和启动器

总工作区 res/light、res/dark 的 SVG 已复制到可安装的 data/shell/statusbar 对应目录，保留资源原色。亮背景使用 light 中的深色图形，暗背景使用 dark 中的浅色图形。系统音量、电池及充电状态、Wi-Fi 和控制中心均使用对应资源；资源没有提供的禁用网络/热点仍使用 SDK glyph 回退。

每个系统图标按自身的全局位置采样壁纸区域，使用 8×4 有界采样点，并计入实际绘制的状态栏可读性渐变。换壁纸时即使整条平均亮度不变，也重新通知局部采样。没有有效背景时使用原有主题回退。当前采样对象是壁纸与其渐变，不是最终合成帧中的其他窗口或视频覆盖层。

Dock 固定应用启动器使用 data/shell/launchpad.svg，来自用户提供的 res/launchpad.svg；不改应用网格中的其他应用图标。

## 验证

独立测试 tests/shell-appearance 编译真实主题跟随器、Appearance 客户端和装饰主题，并编译 shell.cpp、wallpaper.cpp、状态栏与 Dock 宿主。私有 D-Bus 验证服务晚于 Shell 出现、单独改变图标主题、之后改变深浅色不覆盖图标主题。亮暗背景资源对照图通过真实 SDK 生成并人工检查。
