# 屏幕键盘首版

## 架构与入口

屏幕键盘位于合成器 Shell 中，使用 SDK 控件绘制。以 Panel + NoFocus 显示，点击按键不应激活键盘窗口或改变正在输入的应用。顶部为玻璃材质，下部键盘为实色，支持明暗主题和系统强调色。

入口：

- Super+Ctrl+K：显示或隐藏；可在设置的键盘快捷键中重新绑定。
- 设置 → 键盘 → 屏幕键盘 → 显示键盘。
- 启动器中的“屏幕键盘”，或 lingmo-screen-keyboard / --show / --hide。
- 会话 D-Bus：org.lingmo.ScreenKeyboard，路径 /org/lingmo/ScreenKeyboard，提供 show、hide、toggle 和 visible 属性。

D-Bus 只暴露显示控制，不提供按键注入方法。组件只在已登录桌面创建；锁屏时拒绝显示和发送按键，已显示的键盘由定时守卫收起。

## 输入行为

- 五行键盘，包含字母、数字、符号页、Tab、Esc、Delete、退格、回车、空格和方向键。
- Shift、Ctrl、Alt 为单次修饰状态，成功输入后复位；Caps 为键盘自身的持续大写状态，不改变物理键盘锁定灯。隐藏和重新打开均清空状态。
- 屏幕字母排列为 QWERTY；用当前客户端 XKB 布局寻找所显示字符的实际 evdev 按键。例如德语布局中的 y 映射到相应物理位置。无法生成的字符给出提示，不强行更换用户布局。
- 通过 Seat::tapKeys 进入现有输入法过滤链路，因此中文组合、候选与切换依赖用户已经配置的输入法。首版不内置拼音词库或候选引擎。
- 不释放已由物理键盘按住的修饰键；主键已被按住时拒绝注入，防止改变其他输入源的状态。
- 开启时优先放到当前输入窗口所在显示器的工作区底部。没有占用独占工作区，不强制移动或缩放应用窗口。

## 首版范围

手动显示；尚无文本框聚焦后的自动弹出、长按连发、滑行输入、独立中文候选栏、拖动调整大小和登录/锁屏输入支持。屏幕键盘不触发合成器全局快捷键，Ctrl/Alt 组合发送给当前应用或输入法。显示区域可能遮挡应用底部，需用户调整窗口。

## 验证

独立验证项目：aurora/tests/keyboard。编译键盘模型、SDK 视图、真实 XKB 转换和 Shell 控制器；测试单次修饰键、大小写、德语键位映射、鼠标点击、透明/实色边界和快捷键 D-Bus 协议。

完整合成器测试：tests/shell/screen_keyboard_test.cpp 验证真实 Seat/WindowManager 下的焦点保持及锁屏行为；tests/accelerator_test.cpp 补充快捷键锁屏限制。应在完整合成器测试环境执行，并在桌面上验证 GTK、Qt、原生 SDK 应用、触摸屏、多屏和实际输入法。

无头截图仅反映控件布局与实色回退，不能证明真实桌面玻璃或输入法交互已经验收。

## 本轮验证结果（2026-11-08）

键盘模型/SDK UI、快捷键 D-Bus 协议、CLI 帮助三个独立测试通过。真实 Shell 控制器及完整 Shell 焦点/锁屏测试源码作为 object target 编译通过；Settings 键盘页面通过 SDK 头文件语法编译检查。合成器和 Settings 中文目录通过 msgfmt 校验，已生成浅色/深色 100% 与 150% 截图。

未完成全合成器链接及真实 Seat/WindowManager 集成测试运行；对象编译通过不代表实际桌面集成验收。真实中文输入法、触摸、多屏及锁屏交互仍待桌面测试。没有安装、提交或推送，验证结束后 WSL 已关闭。

## 交互优化

修饰键启用时在标题右侧显示当前组合，并以系统强调色标记按键；成功输入后单次修饰键及提示同步清除。回车键保持较轻的强调色，窄按键自动缩小文字。切换输入窗口时清除旧修饰状态并将面板移动到新窗口所在显示器。按键提示区解释单次修饰、大小写及删除操作。
